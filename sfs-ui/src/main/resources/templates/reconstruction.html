Reconstruction

Reconstruction regenerates a new text document from an object's semantic memory. The result is semantically equivalent, not byte-for-byte identical — the original wording is not recoverable once the raw file is gone.

Starting a reconstruction

Open an object from the Objects screen and use its reconstruct button. Reconstruction never starts automatically, and searching for a record never triggers it.
