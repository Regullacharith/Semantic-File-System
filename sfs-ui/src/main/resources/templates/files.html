About semantic deletion

"Delete raw data" removes the original bytes but keeps the Semantic Record, which remains searchable and can be used to reconstruct a new artifact. It is refused until the file has been analyzed and its Semantic Record durably committed.

This build uses mock data. No semantic analysis is performed and no Semantic DNA is produced.
