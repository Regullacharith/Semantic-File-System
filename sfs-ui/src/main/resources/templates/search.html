About these results

Search returns Object IDs and the evidence behind each match. It never reconstructs a file: reconstruction is a separate action you start explicitly.

This build uses a mock search service. Matching is keyword overlap against a fixed sample corpus — there are no embeddings, no vector index and no reranking. Real semantic retrieval arrives with the Memory System and Search Engine milestones.
