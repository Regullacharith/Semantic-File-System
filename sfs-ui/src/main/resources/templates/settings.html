Security and privacy

SFS separates understanding a document from retaining its sensitive values. A detected secret is replaced by a protected reference describing its role; the exact value is either discarded or held in an encrypted store, never placed in ordinary semantic memory.

Enforced guarantees

  • Enforced Embeddings are never generated from plaintext secrets.
  • Enforced Logs never contain plaintext secrets.
  • Enforced Unrestricted Semantic DNA never contains plaintext secrets.
  • Enforced Resolving a protected reference always requires authorization.

These are architectural invariants, not preferences. They are reported here rather than offered as options because the system is not permitted to operate without them.
